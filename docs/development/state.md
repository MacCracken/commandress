## Version

**1.1.6** — released 2026-08-26. **P-1 audit + security release.** A five-dimension sweep of the 1.1.5 codebase, paired with live attack testing against the built binary, found **arbitrary command execution in both shipped shell adapters** (P-01, HIGH): `cmdrs` correctly strips control bytes but passes `$`/`(`/`)`/`%` through as text (they are legal in a branch name), and `adapters/zsh.sh` (`setopt prompt_subst`) plus `adapters/bash.sh` (bash's default `promptvars`) then handed that string to the shell **as a script** — so a repo shipping `.python-version` = `$(touch /tmp/x)` ran it on every redraw. Fixed by removing `prompt_subst` (never needed: `PROMPT` is assigned from `$( )` in `precmd`, so it holds finished bytes), `shopt -u promptvars`, and `%`-doubling for zsh's separate escape channel. Three more HIGHs came from the parallel-read track: **a FIFO in a hostile repo hangs the prompt forever** (A-01 — `open(2)` on a FIFO blocks and no watchdog covers file reads; reproduced on all five probe paths, and tar preserves FIFOs), **the watchdog abandons its budget** when a child closes stdout and keeps running (A-02 — 30 s against a 5 ms budget), and **the CI lock guard was inert** (A-03 — an earlier `cyrius deps` step overwrote the file it compared against). Also fixed: bash reconstructing ESC from `\e` after F-1 (A-04), UTF-8 C1 controls passing the sanitizer (A-05), the config-warning path echoing raw bytes (A-06), a right-prompt parse error rendering the LEFT prompt (A-07), `vcs_render`'s 12,416-byte frame exceeding the agnos init stack (A-08), a symlinked cache dir defeating F-3 (A-11), a one-sided cache TTL (A-12), CI least-privilege + action SHA-pinning + pipefail (A-09/A-10/A-13), CI piping an installer from `main` (P-07), `cache_put` renaming short writes into place (P-04), the unknown-segment warning (P-02), unchecked stdout writes (P-03), an unguarded `alloc` at the sanitize chokepoint (P-06), and a dependency on cmdit's private `_cmdit_eprint` (P-08). Suite **295 → 304**; `render_prompt` unchanged at **10.86 µs**; `--agnos` clean. Report: [docs/audit/2026-08-26-audit.md](../audit/2026-08-26-audit.md). ## Role

Structured shell prompt renderer for [agnoshi](https://github.com/MacCracken/agnoshi) (and eventually bash/zsh). Binary name: `cmdrs`. Sovereign-stack equivalent of [starship](https://starship.rs/), in Cyrius.

- `--agnos` cross-build stays clean (**203,464 B** at 1.1.5; was 164,056 B at 1.1.4). Clean since the 1.1.4 `cache.cyr` fix; Cyrius 6.5.1 made the `sys_stat` arity mismatch a hard error.

## Dependencies

Direct (declared in `cyrius.cyml`):

- stdlib — `string`, `fmt`, `alloc`, `io`, `vec`, `str`, `syscalls`, `assert`, `args`, `bench` (and via includes: `cyml`, `toml`, `fnptr`). `args` + `bench` were declared at 1.1.5: both were always compiled in via includes, and cmdit's `dist/cmdit.deps` sidecar requires them in scope.
- **cmdit** `1.2.4` — first-party AGNOS CLI / argument-parsing distlib, `[deps.cmdit] modules = ["dist/cmdit.cyr"]`, pinned by git tag (`path = "../cmdit"` deliberately commented out — a path override silently beats its tag and the lock cannot detect the substitution). commandress's **first non-stdlib dependency**, adopted at 1.1.5 per [ADR 0008](../adr/0008-cli-parsing-via-cmdit.md). Compiled in; the binary stays static, and no runtime dependency is added.

The declared `[deps]` surface is stable across releases; the **vendored `lib/` snapshot** is re-synced to the pinned toolchain per refresh (`cyrius lib sync --full`). Last resync: **1.1.4 → the 6.5.35 pin** (60 libs updated, 2 added, 0 removed). A stale snapshot surfaces at build time as a `./lib/ shadows version-pinned …/lib — N bundled lib(s) differ` warning — the signal to re-sync. Note `cyrius deps` alone does **not** refresh the snapshot; it resolves declared `[deps]`, which for a stdlib-only project is a no-op (no `cyrius.lock` is produced, so `cyrius deps --verify` reports none — expected, not a fault).

External (non-AGNOS, third-party): none, and none planned. The 1.1.5 cmdit adoption is a *first-party AGNOS source* dep — vendored, tag-pinned, compiled in — which ADR 0008 admits as a distinct category from the runtime deps that stay forbidden. `cyrius.lock` (119 entries, 1 commit-pinned) is committed as of 1.1.5.
